# Agent improvement log

Record potential improvements to code or agent instructions here when they
are identified, so later work can review them. Keep each entry actionable,
distinguish observed evidence from hypotheses, and update an existing matching
entry instead of duplicating it. Include improvements handled during the
current task, marking them resolved with the outcome and validation.

This document holds suggestions for review. The [acquisition roadmap](TODO.md)
owns planned implementation work; link its relevant item when a suggestion is
scheduled. Recording a suggestion does not authorize implementing it or
expanding task scope. Keep secrets, private source material and private host
paths out of entries.

## Entry format

Use a stable identifier such as `AI-001` and a short descriptive title.

- **Identified:** YYYY-MM-DD.
- **Affected files or instructions:** Project-relative paths and relevant sections.
- **Evidence:** Observations, references and any unverified hypothesis.
- **Proposed improvement and benefit:** A concrete change and why it would help.
- **Status:** Proposed, planned, resolved or declined; include the reason or outcome.
- **Follow-up:** Roadmap link, next review step, or resolution and validation evidence.
